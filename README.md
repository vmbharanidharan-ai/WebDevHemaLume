# HemaLume

Marketing site for **HemaLume** — an offline, smartphone-based blood-smear triage concept for frontline clinics.

This is a triage-oriented product narrative. The site does not claim independent leukemia diagnosis, regulatory clearance, clinical validation metrics, or finalized hardware specifications.

## Stack

- Next.js 16 (App Router)
- React 19
- TypeScript
- Manrope via `next/font`
- Hand-crafted CSS (no component library)

## Run locally

Node.js 20+ recommended.

```bash
npm install
npm run dev -- --port 4317
```

Open [http://127.0.0.1:4317](http://127.0.0.1:4317).

## Build

```bash
npm run build
npm start -- --port 4317
```
